# Demographic Data Analysis Using NumPy

## 📌 Project Overview

This project focuses on analyzing demographic data using Python and NumPy.

The main goal of this project is to practice NumPy concepts by applying them to a real dataset and answering different data analysis questions.

## 🛠️ Technologies Used

- Python
- NumPy
- Jupyter Notebook

## 🔍 Analysis Performed

Some of the questions explored in this project include:

- What is the average age of the people?
- How many people work more than 40 hours per week?
- How many people earn more than $50K?
- How many people have capital gain greater than 0?
- How many males earn more than $50K?
- How many females earn more than $50K?
- Which race category has the highest number of people?
- Which age group works the most hours?
